# Portfolio - Félix Parendeau Millerioux

Bienvenue sur le dépôt de mon portfolio personnel. Ce site a pour but de présenter mon parcours d'étudiant développeur Fullstack, mes compétences techniques et les projets que j'ai réalisés.

##  À propos

Actuellement en première année de Bachelor Développeur FullStack à **CODA_ Orléans**, j'ai conçu ce site pour centraliser mes travaux et offrir un accès rapide à mon CV et mes réseaux.

##  Technologies utilisées

Ce portfolio a été réalisé de manière native pour assurer performance et maîtrise du code :

* **HTML5** : Structure sémantique de la page.
* **CSS3** : Design responsive (Mobile, Tablette, Desktop), animations et variables CSS (`:root`).
* **JavaScript** : Gestion des interactions (défilement fluide, etc.).
* **FontAwesome** : Pour les icônes.

##  Fonctionnalités

* **Liens rapides** : Accès direct à mon LinkedIn, GitHub et téléchargement du CV.
* **Design Responsive** : Adaptation fluide du mobile aux grands écrans.
* **Timeline** : Visualisation de mon parcours scolaire et professionnel.
* **Section Projets** : Présentation de mes réalisations (RideTeam, Fair Count, The League, etc.).
